# Abdul Rehman Samad Portfolio

## Publish free with GitHub Pages

1. Create a free GitHub account at https://github.com if needed.
2. Create a new public repository named `portfolio`.
3. Upload every file and folder in this directory, including `assets/`.
4. In that repository, select **Settings** → **Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch `main`, folder `/ (root)`, then click **Save**.
7. In a few minutes, GitHub shows your public address: `https://YOUR-USERNAME.github.io/portfolio/`.

This site is plain HTML, CSS, and JavaScript, so it does not require a paid server, database, or build process. Any change you upload to the repository republishes the website.

## Make it more professional later

- Buy a custom domain only if you want one (for example, `abdulrehman.dev`); GitHub Pages hosting itself remains free.
- In GitHub **Settings** → **Pages**, add the custom domain and follow GitHub's displayed DNS instructions. Enable **Enforce HTTPS** once it becomes available.
- Update the five `+ Add project link` buttons in `index.html` by replacing `href="#project-links"` with each project's live URL or GitHub repository.
